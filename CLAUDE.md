# Claude guidance

This is a two-project Astryon monorepo. Follow the repository-wide instructions in [`AGENTS.md`](./AGENTS.md) first.

For application work, also read [`app/AGENTS.md`](./app/AGENTS.md). For marketing-site work, read [`web/AGENTS.md`](./web/AGENTS.md). The complete documentation map and reading order are in [`docs/README.md`](./docs/README.md).

Production deployment instructions are in [`docs/DEPLOYMENT_HANDOFF.md`](./docs/DEPLOYMENT_HANDOFF.md), and deployment review findings are recorded in [`docs/REVIEW_NOTES.md`](./docs/REVIEW_NOTES.md).

Keep the two projects independently deployable from Vercel with Root Directories `app` and `web`. Do not commit secrets or local environment files.
